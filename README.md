# EEG-Based Sleep Stage Classification

## Overview

This project explores the application of deep learning to automated sleep stage classification using Electroencephalography (EEG) signals.

EEG recordings capture electrical activity in the brain and provide valuable information about sleep architecture. By analyzing these signals, machine learning models can identify distinct sleep stages, offering a computational approach to understanding sleep patterns and brain activity.

The project implements an EEG classification pipeline to distinguish between five sleep stages:

- **W:** Wake
- **N1:** NREM Stage 1
- **N2:** NREM Stage 2
- **N3:** NREM Stage 3
- **REM:** Rapid Eye Movement

## Objectives

- Explore EEG as a source of neural time-series data.
- Apply preprocessing and segmentation techniques to physiological signals.
- Develop a deep learning model for multiclass sleep stage classification.
- Evaluate classification performance and investigate challenges associated with distinguishing sleep stages.

## Technologies

## Relevance

This project serves as an exploration of neural signal analysis and machine learning in computational neuroscience, with broader relevance to biomedical AI and neurotechnology.

It also provides a foundation for further exploration of EEG-based applications, including brain-computer interfaces and neural decoding.
